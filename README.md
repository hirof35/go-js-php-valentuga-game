# ヴァーレントゥーガWeb（Go-JS-PHP 連携デモゲーム）

往年の名作フリーゲーム『ヴァーレントゥーガ』の持つ「内政・雇用・リアルタイムバトル・セーブ同期」のコアエッセンスを、現代のWeb技術（Go + JavaScript + PHP）で再現したマルチ言語連携の実験的ミニゲームプロジェクトです。

## 📌 システム概要

本システムは、3つの異なる技術レイヤーがそれぞれの強みを活かして連携するハイブリッド構成をとっています。

       [ フロントエンド ]
        JavaScript (UI / 戦闘リアルタイム描画)
           /               \
   (API通信:8080)       (データ保存:8000)
         /                   \
[ バックエンドコア ]      [ ストレージ・データ管理 ]
Go言語 (状態管理/検証)      PHP (save.php / ロード・セーブ保持)


1. **フロントエンド (HTML5 / JavaScript)**
   - ゲーム画面の描画、リアルタイムバトルのシミュレーション（部隊配置や簡易AI処理）。
   - GoおよびPHPのAPIと非同期通信（`fetch`）を行い、状態を画面に反映。
2. **バックエンドコア (Go言語 - ポート 8080)**
   - プレイヤーの資金（ゴールド）や領地所有権などの「ゲームのマスターデータ」をメモリ上で安全に一元管理。
   - 雇用時の資金チェック、戦闘開始時の部隊データ生成、リセット処理などを高速に処理。
3. **データストレージ (PHP - ポート 8000)**
   - 永続化（セーブデータのファイル書き出し・読み込み）を担当。
   - `save.php` などを介して、Goから送られてきた最新の状態をローカルに保存/復元。

---

## 🛠️ 機能一覧

- **内政・ユニット雇用機能**: 資金を消費して「ナイト」や「メイジ」を雇用（Go側で資金不足チェックを厳密に実施）。
- **リアルタイムバトル**: 自軍と敵軍のユニットが自動で索敵・交戦する簡易戦闘システム（戦闘結果に応じてGo側の領地データが動的に書き換わります）。
- **データ同期（セーブ＆ロード）**: Goのメモリ状態をPHPサーバーを経由してファイルとして保存、次回起動時に再同期。
- **データ初期化機能**: データをボタン一つで初期状態（1000G、初期領地配置）へリセット可能。

## 🚀 起動方法 (ローカル環境)

XAMPP環境、およびGo言語がインストールされている環境を前提としています。
CORS（クロスオリジンリソース共有）の競合を避けるため、**2つのポート**を同時に立ち上げます。

### 1. バックエンド（Go）の起動
パワーシェル等のターミナルを開き、プロジェクトのルートディレクトリで以下を実行します。
```powershell
cd C:\xampp\htdocs\php_code\go-js-php-valentuga-game
go run main.go
起動すると、http://localhost:8080 でAPIおよび静的ファイル（index.html）の配信が始まります。

2. ストレージ（PHP）の起動
もう一つ新しいターミナル（タブ）を開き、同じディレクトリでPHPのビルトインサーバーを起動します。

PowerShell
cd C:\xampp\htdocs\php_code\go-js-php-valentuga-game
php -S localhost:8000
これで http://localhost:8000/save.php 経由でのセーブ/ロード通信が可能になります。

3. ゲームのプレイ
ブラウザを開き、以下のURLにアクセスしてください。

http://localhost:8080/

⚠️ 開発時の注意点（トラブルシューティング）
ERR_CONNECTION_REFUSED が出る場合
PHPサーバー（ポート8000）か、Goサーバー（ポート8080）のどちらかが起動していません。2つのターミナルでそれぞれコマンドが走っているか確認してください。

404 Not Found が出る場合
main.go 内のルーティング設定（apiMux.HandleFunc）の記述順序が、サーバーの起動命令（ListenAndServe）より上に書かれているか確認してください。

CORSエラーが出る場合
ブラウザの安全機能によりポートを跨ぐ通信がブロックされるのを防ぐため、main.go にはすべてのリクエストに対してCORSヘッダー（Access-Control-Allow-Origin: *）を強制付与するラッパーが組み込まれています。
